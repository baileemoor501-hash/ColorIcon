# 主题包生成工具需求文档（V2.0）
## 1. 需求概述
基于现有图标颜色编辑工具（支持图标颜色/形状/装饰编辑、JSON导入导出），新增**壁纸导入预览模块**与**主题包ZIP导出功能**，升级为一站式主题包生成工具，支持用户快速整合壁纸与图标配置，导出标准化主题包（含壁纸、配置JSON、预览图），并优化手机端模拟预览体验。

## 2. 界面修改详情
### 2.1 右侧编辑区域
- 在现有「颜色」「装饰」「形状」分页右侧，新增「壁纸」分页标签（图标：🖼️），切换至该分页时显示壁纸模块功能区。
- 分页样式保持一致：选中状态高亮显示，未选中状态默认灰色，hover时显示边框提示。

### 2.2 功能按钮区
- 在现有「保存方案」「管理方案」「导出JSON」「导入JSON」「导入颜色值」按钮下方，新增「导出ZIP包」按钮：
  - 按钮样式：与现有按钮统一（圆角矩形、蓝色背景、白色文字），hover时背景加深。
  - 按钮位置：居右排列，与上方按钮间距一致（10px）。

## 3. 核心功能需求
### 3.1 壁纸模块
| 功能点                | 详细要求                                                                 |
|-----------------------|--------------------------------------------------------------------------|
| 导入入口              | 模块顶部显示「导入壁纸」按钮（图标+文字：📤 导入壁纸），居中排列。         |
| 导入方式              | 1. 本地导入：支持多选（按住Ctrl/Shift批量选择），支持格式：JPG、PNG、WEBP；<br>2. 链接导入：按钮右侧新增「链接导入」弹窗入口，输入合法HTTP/HTTPS图片链接后点击「确认导入」。 |
| 格式处理              | 导入后自动将壁纸转为JPG格式（保证兼容性），保留原分辨率（最大支持8192×4192像素，超出时提示「图片分辨率过大，建议压缩至8K以内」）。 |
| 缩略图生成            | 自动生成19.5:9比例缩略图（尺寸：100×180px），清晰显示壁纸主体内容。       |
| 网格展示              | 1. 缩略图按「每行4个」网格排列，间距15px，超出自动换行；<br>2. 网格区域支持垂直滚动（最大显示10行，超出时显示滚动条）。 |
| 单选交互              | 1. 点击缩略图选中：显示蓝色边框（2px）+ 白色勾选图标（右上角）；<br>2. 已选中时再次点击取消选中；<br>3. 最多选中1张壁纸（后续导出用），选中新壁纸时自动取消原选中项。 |
| 实时预览              | 选中壁纸后，左侧手机模拟预览区背景实时更新为该壁纸。                       |
| 错误提示              | 1. 导入不支持格式文件：提示「请选择JPG/PNG/WEBP格式图片」；<br>2. 链接无效/无法访问：提示「图片链接无效，请检查后重试」；<br>3. 多选时包含不支持格式：仅导入合法文件，提示「部分文件格式不支持，已跳过」。 |

### 3.2 导出ZIP包功能
| 功能点                | 详细要求                                                                 |
|-----------------------|--------------------------------------------------------------------------|
| 触发逻辑              | 点击「导出ZIP包」按钮时触发，若未选中壁纸则弹窗提示「请先导入并选中壁纸」。 |
| 命名弹窗              | 1. 弹窗类型：模态弹窗（居中显示，遮罩层半透明）；<br>2. 输入框：默认名称「theme_package_YYYYMMDD」（日期自动填充），支持自定义（长度1-30位，禁止特殊字符：\/:*?"<>|）；<br>3. 按钮：「确认导出」（蓝色）、「取消」（灰色），输入非法内容时「确认导出」置灰并提示「请输入合法名称」。 |
| 保存路径              | 弹窗确认后，弹出「选择保存路径」对话框，默认路径为系统桌面，支持自定义选择文件夹。 |
| ZIP包结构             | 压缩包内包含3个文件（文件名固定）：<br>1. wallpaper.jpg（选中的壁纸文件，JPG格式）；<br>2. icon_color_adapter.json。 |
| 导出反馈              | 1. 导出中：显示进度条（文字提示「导出中...」，进度百分比实时更新）；<br>2. 导出成功：弹窗提示「导出成功！」，提供「打开文件夹」按钮（直接定位到ZIP包位置）；<br>3. 导出失败：提示「导出失败，请检查保存路径是否可写」。 |

## 4. 后续优化需求（预览体验增强）
### 4.1 手机模拟预览区
- 位置：工具左侧固定区域，尺寸严格遵循19.5:9比例（宽度300px，高度550px），外框模拟手机外壳（黑色边框+圆角设计）。
- 背景：实时同步壁纸模块选中的壁纸，填充整个预览区，无拉伸变形。

### 4.2 图标预览规则
| 规则项                | 详细要求                                                                 |
|-----------------------|--------------------------------------------------------------------------|
| 图标尺寸              | 宽度=预览区宽度的1/4（300px÷4=75px），图标为正方形（75×75px），保持清晰无模糊。 |
| 排列方式              | 1. 按「4列」均匀分布，列间距10px，行间距15px；<br>2. 底部固定显示4个核心图标：phone（电话）、sms（短信）、browser（浏览器）、camera（相机），优先填充最后一行；<br>3. 其他图标按工具中配置顺序，从第一行第一列开始填充，不足时显示空白占位（灰色透明框）；<br>4. 最多显示6行（24个图标），超出时显示垂直滚动条（滚动时壁纸背景固定不动）。 |

### 4.3 预览图导出功能
- 预览区底部新增「导出预览图」按钮（样式与现有按钮统一），点击后导出PNG格式预览图：
  - 分辨率：预览区2倍高清图（600×1100px），保证清晰度；
  - 文件名：theme_preview.png；
  - 导出逻辑：后续版本中，该文件自动加入ZIP包；当前可支持单独导出（保存路径与ZIP包一致）。

## 5. 非功能需求
### 5.1 兼容性
- 支持系统：Windows 10+、MacOS 10.15+；
- 支持图片分辨率：最小320×590px（19.5:9最小比例），最大8192×4192px。

### 5.2 操作体验
- 响应速度：导入单张10MB以内图片≤2秒，导出10MB以内ZIP包≤3秒；
- 交互反馈：所有操作（导入、选中、导出）均有明确视觉提示（图标、文字、动画），无静默失败。

### 5.3 错误处理
- 网络异常（链接导入时）：提示「网络错误，请检查网络连接后重试」；
- 文件损坏（本地导入时）：提示「部分文件损坏，已跳过」；
- 权限不足（导出时）：提示「无保存权限，请选择其他路径」。

## 6. 约束条件
- 壁纸仅支持单张导出（ZIP包内仅包含1张选中的壁纸）；
- JSON配置文件字段不可自定义，需与现有工具导出格式保持兼容；
- 预览区图标仅展示工具中已配置的图标，未配置图标显示占位符。
