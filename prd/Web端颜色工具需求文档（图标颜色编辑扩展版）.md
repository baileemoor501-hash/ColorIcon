# Web端颜色工具需求文档（图标颜色编辑扩展版）

## 一、项目概述（补充）
在原有Web端颜色工具（支持Normal、Linear、RadialGradient颜色类型）基础上，新增图标颜色编辑与预览功能。通过加载分层图标资源（前景分层图+固定背景图），实现对图标前景色（多层）和背景色（单层）的精细化编辑，支持实时预览效果，并能导出编辑后的图标及符合指定格式的颜色配置JSON，满足图标设计与开发的色彩一致性需求。

## 二、核心功能需求（补充）

### 2.5 图标资源管理功能
- **分层资源处理**：
  - 识别文件夹内下划线后缀的分层前景图（如`allapps_1.png`、`allapps_2.png`），同一前缀的图片视为同一图标的多层前景（按数字序号排序）
  - 所有图标统一叠加三星形状背景图（`icon_base.png`），形成完整图标（前景分层依次叠加于背景之上）
- **图标包切换**：支持切换不同文件夹的前景图资源（`iconPack`切换），切换后实时加载新文件夹下的分层资源并更新预览

### 2.6 图标预览展示功能
- **网格布局**：所有图标按n行m列网格形式展示，行列数支持响应式调整（根据屏幕尺寸自动适配或手动设置）
- **实时预览**：颜色编辑操作（如修改前景色、背景色参数）后，预览区图标实时更新效果，直观反映颜色变化
- **层级可视化**：支持临时高亮显示某一前景分层（单独显示该层颜色效果），便于精准编辑

### 2.7 图标颜色编辑功能
- **分层颜色管理**：
  - **前景色（fg）**：支持多层颜色配置，层数与图标分层数量对应
    - 提供"添加层"、"删除层"按钮，允许调整前景色层数
    - 若前景色层数少于图标分层数量，未配置的分层默认使用最后一层的颜色配置
  - **背景色（bg）**：仅支持单层颜色配置，作用于`icon_base.png`背景图
- **颜色编辑工具集成**：每层颜色（前景各层、背景层）均集成现有颜色编辑工具，支持：
  - Normal（固定色）：通过颜色选择器或输入框设置单一颜色
  - LinearGradient（线性渐变）：配置渐变角度、颜色点及位置
  - RadialGradient（径向/圆形渐变）：配置中心点、扩散范围、角度（圆形渐变）等参数
- **编辑交互**：选中某层（前景层或背景层）后，右侧编辑区自动加载该层的颜色配置工具，修改后即时同步至预览区

### 2.8 导出功能（扩展）
- **图标导出**：支持将当前预览的图标（单个或全部）导出为图片格式（如PNG），保留透明通道
- **颜色配置JSON导出**：严格按照指定格式导出颜色编辑配置，结构说明：
  - `icon_colors`：数组，包含所有图标的颜色配置
  - 单个图标配置：
    - `pre_method`：预留字段（暂为空）
    - `fg`：数组，前景色分层配置，每个元素对应一层的颜色信息（包含`colorTypes`、`colors`、`color_hex`、`gradient`）
    - `bg`：数组，背景色配置（仅一个元素，结构同`fg`的单个元素）
  - 字段约束：`colorTypes`、`colors`与渐变参数需与现有颜色工具的JSON格式兼容，`color_hex`同步记录对应颜色的十六进制值

## 三、UI/UX设计需求（补充）
- **布局结构**：采用左右分区布局
  - 左侧：图标预览区，占比约60%，以网格形式展示所有图标，支持滚动查看
  - 右侧：编辑区，占比约40%，包含功能选项卡及编辑控件
- **编辑区组件**：
  - 选项卡：包含"颜色"（默认显示）、"装饰"、"形状"、"阴影"、"iconPack"等（后续扩展）
  - 颜色编辑面板：
    - 前景色区域：显示当前前景层数，每层对应"删除"按钮和颜色编辑工具入口，底部有"添加层"按钮
    - 背景色区域：固定显示一层，包含颜色编辑工具入口
    - 颜色工具集成：点击某层的编辑入口，展开对应颜色类型（Normal/Linear/Radial）的配置界面（复用原有工具UI）
- **交互反馈**：
  - 选中某图标时，预览区高亮显示该图标，编辑区同步加载其颜色配置
  - 颜色参数调整时，预览区图标实时刷新（节流处理避免性能问题）
  - 导出操作显示进度提示，完成后提供下载链接

## 四、技术需求（补充）
- **图标合成渲染**：采用Canvas或CSS图层叠加技术，实现前景分层与背景图的合成，支持按配置的颜色（或渐变）对分层图进行着色处理
- **颜色工具联动**：将现有颜色编辑工具（Normal/Linear/Radial）封装为可复用组件，通过数据绑定实现与图标分层颜色的联动更新
- **JSON处理**：
  - 实现颜色配置JSON的生成逻辑，确保与指定格式完全一致
  - 支持JSON导入功能，可还原图标颜色配置（包括前景分层、背景及各类渐变参数）
- **性能优化**：
  - 图标预览区采用虚拟滚动（针对大量图标场景）
  - 颜色编辑操作采用防抖/节流，减少渲染次数
  - 图标着色处理使用Web Worker避免主线程阻塞

## 五、用户场景（扩展）
1. UI设计师编辑图标色彩方案，通过多层颜色配置实现复杂图标效果，导出图片用于设计稿
2. 开发者通过导出的JSON配置，直接将图标颜色参数应用到代码中，保证设计与开发的色彩一致性
3. 产品团队在评审图标风格时，通过实时编辑颜色参数快速对比不同方案效果
4. 设计系统维护者统一管理图标颜色配置，通过导入/导出JSON实现团队内方案共享

## 六、兼容性说明（补充）
- 图标着色效果在不同浏览器中保持一致，对于不支持高级渐变的环境，采用降级方案（如将渐变转为近似固定色）
- 导出的PNG图标兼容主流设计工具（如Figma、Sketch）和开发场景
- 确保颜色配置JSON在各端（Web/移动端）解析时的兼容性，字段含义与原有颜色工具保持一致

## 图标颜色编辑导出JSON格式补充说明

基于颜色工具的JSON格式规范与图标颜色编辑需求，现将完整导出JSON格式补充如下，确保两者字段兼容且满足图标分层编辑场景：

## 完整JSON格式定义
```json
{
  "icon_colors": [
    {
      "pre_method": "", // 预留字段，暂为空字符串
      "fg": [
        {
          "colorTypes": ["color_normal", "line_gradient"], // 每层颜色的类型数组（与colors对应）
          "colors": [
            -10123164, // 颜色1（ARGB整数格式）
            -133379    // 颜色2（ARGB整数格式）
          ],
          "color_hex": [
            "#FF658864", // 对应colors[0]的十六进制值（含Alpha通道）
            "#FFFEEAAD"  // 对应colors[1]的十六进制值
          ],
          "gradient": {
            "angle": 45, // 线性渐变角度（仅line_gradient类型有效，0-360）
            "positions": [0.0, 1.0], // 颜色点位置（0.0-1.0，与colors长度一致）
            "radial": 0.8, // 径向渐变范围（仅radial_gradient有效，0.0-1.0）
            "xOffset": 0.5, // 径向中心点X坐标（仅radial_gradient有效，0.0-1.0）
            "yOffset": 0.5, // 径向中心点Y坐标（仅radial_gradient有效，0.0-1.0）
            "type": "line_gradient" // 该层颜色类型：color_normal/line_gradient/radial_gradient/sweep_gradient
          }
        },
        {
          "colorTypes": ["radial_gradient"],
          "colors": [
            -2236963
          ],
          "color_hex": [
            "#FF00FFFF"
          ],
          "gradient": {
            "angle": 0, // 圆形渐变（sweep_gradient）时为起始角度
            "positions": [], // 单一颜色或无需位置时为空数组
            "radial": 1.0,
            "xOffset": 0.3,
            "yOffset": 0.7,
            "type": "radial_gradient"
          }
        }
      ],
      "bg": [
        {
          "colorTypes": ["color_source"], // 支持原始图标主色调（特殊Normal类型）
          "colors": [
            -16777216
          ],
          "color_hex": [
            "#FF000000"
          ],
          "gradient": {
            "angle": 0,
            "positions": [],
            "radial": 1.0,
            "xOffset": 0.5,
            "yOffset": 0.5,
            "type": "color_source"
          }
        }
      ]
    }
  ]
}
```

## 字段映射与约束说明
1. **与颜色工具格式的兼容关系**：
   - `fg`/`bg`数组中的每个对象继承颜色工具的JSON结构，通过`gradient.type`关联颜色类型（对应颜色工具的`type`字段）
   - `gradient.angle`/`positions`/`radial`/`xOffset`/`yOffset`完全复用颜色工具的参数定义，仅在对应类型下有效（如`angle`仅对`line_gradient`和`sweep_gradient`有效）

2. **新增字段说明**：
   - `color_hex`：与`colors`数组一一对应，存储ARGB整数转换后的十六进制字符串（格式`#AARRGGBB`），便于人工识别颜色
   - `colorTypes`：记录每层中各颜色的原始类型（与颜色工具`colorTypes`一致），支持混合类型场景（如渐变中包含原始取色）

3. **分层特殊规则**：
   - 若`fg`数组长度小于图标实际分层数，导出时仍按实际配置层数记录，应用时自动将最后一层配置复用至剩余分层
   - `bg`数组固定长度为1，仅支持单层配置，`gradient.type`支持所有颜色工具类型

4. **数据校验规则**：
   - `colors`与`color_hex`长度必须一致
   - `positions`长度必须与`colors`一致（仅渐变类型有效，Normal类型可为空数组）
   - `gradient.type`必须为颜色工具支持的类型（`color_normal`/`color_source`/`line_gradient`/`radial_gradient`/`sweep_gradient`）
   - 数值型参数（`angle`/`radial`等）需符合范围约束（如`xOffset`必须在0.0-1.0之间）

该格式既满足图标分层颜色编辑的场景需求，又保持了与基础颜色工具JSON格式的兼容性，可直接用于导入还原编辑状态或开发端渲染实现。
