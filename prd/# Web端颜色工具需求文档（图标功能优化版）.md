# Web端颜色工具需求文档（图标功能优化版）

## 一、优化概述
在原有图标颜色编辑功能基础上，重点优化图标资源导入与管理、颜色逻辑扩展、数据保存与导出能力，增强工具的自定义灵活性和场景适配性，保持与原有颜色类型（Normal/Linear/Gradient）及合成逻辑的兼容性。


## 二、核心优化需求

### 2.1 图标资源导入与管理优化
#### 2.1.1 自定义图标导入功能
- **导入支持**：允许用户上传自定义图标资源（替换内置资源），支持单文件或多文件批量导入：
  - 前景图：需遵循命名规则（同一前缀+数字后缀，如`icon_fg_1.png`、`icon_fg_2.png`），系统按序号自动识别分层顺序
  - 背景图：支持上传单个背景图（建议命名为`icon_base.png`），作为所有前景层的统一背景
  - 格式限制：仅支持带透明通道的PNG格式，确保分层合成效果
- **导入校验**：自动校验文件命名规范性（前景图序号连续性）、格式有效性，不符合时提示错误原因（如"前景图序号不连续，请检查文件命名"）

#### 2.1.2 图标资源保存与切换
- **资源存储**：将用户导入的图标资源（含前景层集合+背景图）作为"图标包"保存，包含以下信息：
  - 图标包名称（用户自定义，如"首页图标集"）
  - 前景图列表（按序号排序）
  - 背景图
  - 导入时间
- **资源管理界面**：
  - 显示所有已保存的图标包列表，支持预览（展示首个前景层+背景图的合成效果）
  - 支持切换图标包（切换后，预览区和编辑区同步更新为当前图标包内容）
  - 支持删除图标包（二次确认，避免误操作）
- **存储方式**：优先使用浏览器`IndexedDB`存储（支持大容量文件），低版本浏览器降级为`localStorage`（需提示容量限制）


### 2.2 颜色逻辑扩展（pre_method参数）
#### 2.2.1 pre_method参数定义
- **作用范围**：用于指定前景色、背景色的颜色处理算法，可独立作用于前景层（每层可单独配置）和背景色
- **参数取值**（初始支持以下类型，预留扩展接口）：
  - ``：无特殊处理（默认值，保持原有颜色逻辑）
  - `invert`：颜色反相（对每个颜色通道进行反转处理）
  - `multiply`：正片叠底混合（前景色与背景色按像素叠加计算）
  - `hue_rotate`：色调旋转（按指定角度旋转色调，需额外参数`rotate_degree`：0°-360°）
- **优先级**：当pre_method存在时，优先按参数对应的算法处理颜色；无参数时，沿用原有逻辑（直接应用配置的颜色/渐变）

#### 2.2.2 处理逻辑
- 前景色：每层颜色配置中新增`pre_method`字段，支持为不同前景层设置不同处理算法
- 背景色：背景色配置中新增`pre_method`字段，统一处理背景色（多色背景时按参数规则处理）
- 实时预览：修改`pre_method`参数后，预览区即时更新处理后的合成效果


### 2.3 背景色多色处理支持
- **数据结构调整**：背景色从单一颜色配置改为数组（`backgroundColors`），支持配置多个颜色（含Normal/Linear/Gradient类型）：
  ```json
  {
    "backgroundColors": [
      { "type": "color_normal", "colors": [-16728999], ... }, // 背景色1
      { "type": "line_gradient", "angle": 45, ... } // 背景色2
    ],
    "pre_method": "multiply" // 背景色处理算法
  }
  ```
- **默认逻辑**：当`pre_method`为空时，仅应用`backgroundColors`数组中的第一个颜色配置
- **多色生效条件**：当`pre_method`为`multiply`等支持多色混合的算法时，按参数规则处理数组中所有背景色（如依次叠加混合）
- **invert,multiply,hue_rotate** 只预留这三个定义，不实现具体算法


### 2.4 JSON数据保存与导出优化
#### 2.4.1 自定义颜色方案保存
- **保存内容**：用户可将当前图标包的颜色配置保存为"颜色方案"，包含：
  - 方案名称（用户自定义）
  - 关联图标包名称（`icon_pack_name`，关联到2.1.2中的图标包）
  - 前景层颜色配置（含每层的`pre_method`）
  - 背景色配置（`backgroundColors`数组+`pre_method`）
  - 保存时间
- **方案管理**：支持查看、重命名、删除已保存的颜色方案，支持一键应用方案（快速还原颜色配置）

#### 2.4.2 导出JSON格式扩展
- **新增字段**：在原有导出JSON中增加`icon_pack_name`字段，标识当前颜色方案对应的图标包名称，示例：
  ```json
  {
    "icon_pack_name": "首页图标集", // 新增：图标资源名
    "icon_colors": [
      {
        "foregroundLayers": [ // 前景层配置（含pre_method）
          { "type": "line_gradient", "pre_method": "hue_rotate", "rotate_degree": 90, ... },
          ...
        ],
        "backgroundColors": [ ... ], // 背景色数组
        "backgroundPreMethod": "multiply" // 背景色处理算法
      }
    ]
  }
  ```
- **导出校验**：导出前自动校验数据完整性（如`icon_pack_name`非空、颜色配置与图标包层数匹配）


## 三、UI/UX设计补充
- **导入区域**：在图标预览区顶部新增"导入图标包"按钮，点击弹出文件选择器（支持拖拽上传），显示导入进度
- **资源切换区**：侧边栏新增"图标包管理"面板，列表展示已保存的图标包，支持切换和删除
- **pre_method选择器**：在前景层/背景色编辑区新增下拉选择框，选择算法后动态显示额外参数输入项（如`hue_rotate`对应角度输入框）
- **背景色编辑区**：从单一颜色编辑改为列表式编辑，支持添加/删除背景色，显示序号标识（无pre_method时高亮第一个生效项）


## 四、技术需求补充
- **文件处理**：实现PNG文件解析与预览，通过Canvas实现图标分层合成（兼容原有合成逻辑）
- **存储管理**：封装`IndexedDB`操作工具类，处理图标包的增删改查及大容量存储
- **颜色算法**：实现`pre_method`对应的颜色处理函数（反相、混合、色调旋转等），兼容ARGB格式与渐变类型
- **数据校验**：新增JSON导出校验规则（`icon_pack_name`非空、颜色数组长度匹配等）
- **性能优化**：多色背景和复杂`pre_method`处理时，采用Web Worker避免主线程阻塞，保证预览流畅


## 五、用户场景扩展
1. 设计师导入自定义图标素材，通过`pre_method`快速尝试"正片叠底"等混合效果，保存方案供后续迭代
2. 开发团队通过`icon_pack_name`关联图标资源与颜色方案，确保代码中图标与配置一一对应
3. 运营人员切换不同图标包，复用已有颜色方案（如将"首页图标"的颜色逻辑快速应用到"个人中心图标"）
4. 新手用户通过预设`pre_method`模板（如"反色主题"），快速生成符合品牌调性的图标色彩
