# 增加配置前景图资源链接
    这是web端编辑配置颜色图标+形状+壁纸的工具，通过icon_pack_name确定前景图图标包资源，现在增加导入前景图zip链接，
    下载并解析zip包，作为图标包

## 界面修改优化
- 在图标编辑预览区域-导入图标包按钮左边位置增加“导入图标包链接”按钮，点击弹窗填写url链接
- 右侧图标包管理列表位置，显示导入的图标包资源，如果是zip导入的图标包，底部增加显示对应的url链接

## 导入图标包zip逻辑

- 导入链接需要判断是否是合法的zip链接
- 解压后的图片资源，根据“导入本地图标包”资源逻辑处理识别分层图标

## 导出json逻辑处理
    原有导入，导出的json，增加icon_pack_url字段，保存之前导入的前景图zip链接
```json
{
  "id": "我的配色方案1",
  "icon_pack_name": "自定义图标包",
  "icon_pack_url": "https:",   //新增url字段
  "pre_method": "keep_first",
  "icon_shape": "ios_roundsq",
  "icon_colors": [
    {
      ..
    

```
- 导出json增加icon_pack_rul字段，存放前景图zip链接，如果是本地的前景图资源，留空字符串
- 导入json时，判断icon_pack_url，有则尝试按导入zip前景图逻辑处理，失败则用默认前景图显示
