# Web端颜色工具需求文档（扩展版）

## 一、项目概述（补充）
在原有功能基础上，扩展颜色类型体系，支持Normal（固定色）、Linear（线性渐变）、Gradient（含径向/圆形渐变）三种核心类型，实现渐变颜色的可视化配置与JSON格式导出，满足更复杂的色彩应用场景。

## 二、核心功能需求（扩展）

### 2.1 颜色类型扩展
- **类型体系调整**：
  - **Normal**：对应原`COLOR_TYPE_NORMAL`，单一固定颜色
  - **Linear**：对应原`LINE_GRADIENT`，线性渐变颜色
  - **Gradient**：包含原`RADIAL_GRADIENT`（径向渐变）和`SWEEP_GRADIENT`（圆形渐变）
- **保留原始图标取色**：`COLOR_TYPE_SOURCE`（原始图标主色调）作为特殊Normal类型子项

### 2.2 渐变颜色配置功能
- **线性渐变（Linear）配置**：
  - 支持设置渐变角度（`angle`）：0°-360°可调节，步长1°
  - 渐变颜色点管理：
    - 支持添加/删除颜色（`colors`数组），至少2个颜色
    - 每个颜色对应位置（`positions`数组）：0.0-1.0范围，支持拖拽调整
    - 实时预览渐变效果随角度和位置变化
- **径向/圆形渐变（Gradient）配置**：
  - 径向渐变：
    - 设置中心点坐标（`xOffset`、`yOffset`）：0.0-1.0范围，支持画布点击定位
    - 扩散范围（`radial`）：0.0-1.0调节渐变大小
  - 圆形渐变（SWEEP）：
    - 支持起始角度和结束角度设置
    - 颜色点按顺时针方向分布配置
- **渐变通用功能**：
  - 颜色点支持通过颜色选择器或输入框修改
  - 支持复制渐变配置、重置当前渐变
  - 预设常用渐变模板（如彩虹渐变、冷暖过渡等）

### 2.3 颜色数据格式规范
- **JSON结构定义**：
```json
{
  "angle": 0, // 线性渐变角度（仅Linear类型有效）
  "colorTypes": ["color_normal", "color_normal"], // 每个颜色的类型（对应colors数组）
  "colors": [
    -16728999, // 颜色1（ARGB整数格式）
    -11763115  // 颜色2（ARGB整数格式）
  ],
  "positions": [
    0.0,  // 颜色1位置（0.0-1.0）
    1.0   // 颜色2位置（0.0-1.0）
  ],
  "radial": 1.0, // 径向渐变范围（仅Gradient类型的径向有效）
  "type": "line_gradient", // 类型：line_gradient/radial_gradient/sweep_gradient/color_normal/color_source
  "xOffset": 0.5, // 径向渐变中心点X坐标（0.0-1.0，仅径向有效）
  "yOffset": 0.5  // 径向渐变中心点Y坐标（0.0-1.0，仅径向有效）
}
```
- **格式说明**：
  - `type`字段映射关系：
    - Normal类型 → `color_normal`
    - Linear类型 → `line_gradient`
    - Gradient类型 → `radial_gradient`或`sweep_gradient`
  - `colorTypes`数组长度与`colors`一致，记录每个颜色的原始类型
  - ARGB整数格式与视觉颜色的双向转换（支持hex/rgb输入转换为ARGB值）

### 2.4 交互增强
- **类型切换逻辑**：
  - 从Normal切换到Linear/Gradient时，自动将当前颜色作为渐变起点
  - 从渐变类型切换到Normal时，默认保留第一个颜色点的值
- **可视化编辑区**：
  - 线性渐变：提供角度拖拽控件和颜色点滑块
  - 径向渐变：显示中心点拖拽手柄和范围调节环
  - 所有渐变类型支持画布直接点击添加颜色点
- **数据交互**：
  - 支持导入上述JSON格式配置并还原渐变效果
  - 导出时自动校验数据合法性（如positions升序、颜色数量匹配等）

## 三、UI/UX设计需求（补充）
- **渐变编辑面板**：采用Tab页区分Linear和Gradient类型，保持操作区域紧凑
- **颜色点交互**：颜色点支持拖拽排序、双击删除，悬停显示详细信息
- **实时预览**：渐变编辑区域与预览区域联动，修改参数即时更新效果
- **响应式适配**：在移动设备上，渐变配置项采用折叠面板形式节省空间

## 四、技术需求（补充）
- 实现ARGB整数与hex/rgb/hsl格式的双向转换工具类
- 渐变渲染引擎：基于Canvas或CSS实现三种渐变类型的精确可视化
- 数据校验：确保导出的JSON符合格式规范（如positions数组递增、坐标值范围合法等）
- 性能优化：渐变参数调整时采用节流处理，避免频繁重绘

## 五、用户场景（扩展）
1. 前端开发者配置UI组件的渐变背景，直接导出JSON或CSS代码
2. 设计师制作图标时，通过工具精确配置渐变参数并应用到设计稿
3. 开发团队通过统一的渐变JSON格式实现设计稿与代码的无缝对接
4. 快速复用历史渐变配置，通过导入功能还原之前的渐变效果

## 六、兼容性说明
- 确保生成的渐变JSON格式兼容各端渲染引擎（Web/移动端）
- 提供渐变效果的降级方案：在不支持某些渐变类型的环境下自动转为近似的Normal颜色
