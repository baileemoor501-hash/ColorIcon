# 新增颜色类型
    在现有的颜色类型中colorType（`color_normal`/`color_source`/`line_gradient`/`radial_gradient`/`sweep_gradient`）
    增加多个颜色类型
- color_generate_near_contrast（根据第一个颜色值，生成一个25色相（绿色系用40）偏移的邻近色，一个对比色）
- color_generate_split_3（根据第一个颜色值，平分色相，分裂成3个颜色）
- color_generate_split_8（根据第一个颜色值，平分色相，分裂成8个颜色）
- 增加可编辑的颜色类型（用户可以手动输入颜色值）

这些新增类型，预览颜色、显示图标预览效果还是按照color_normal的方式显示，不实现具体的颜色效果
保存json时，同步保存颜色类型
```
...
    "fg": [
            {
            "colorTypes": [
                "color_generate_split_8"  //对应的颜色类型
            ],
            "colors": [
                -292346
            ],
            "color_hex": [
                "#FFFB8A06"
            ],
        ...
```
